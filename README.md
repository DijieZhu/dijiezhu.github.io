# Dijie Zhu · Personal portfolio

A static research and industry portfolio, hosted on GitHub Pages.

## Preview

Run `python3 -m http.server 8000` from this directory, then open http://localhost:8000.
No build step or package installation is required.

## Content

- `index.html`: About, Research, Resume, Photos, and Contact sections.
- `assets/css/style.css`: original vCard template styles.
- `assets/css/portfolio.css`: personal styling and responsive/accessibility adaptations.
- `assets/js/portfolio.js`: section navigation, browser history, mobile sidebar, and photo viewer.
- `assets/css/flywheel.css` and `assets/js/flywheel.js`: animated circular lifelong robot learning diagram on About, with pause/resume, selectable stages, and reduced-motion support.
- `avatar.jpg` and `cv.pdf`: portrait and CV.
- `Misc/gallery.json` and `Misc/`: photography.
- `misc.html` and `stylesheet.css`: original gallery, retained at its existing URL.

The flywheel repeats Learning / Continual Learning → Evaluation → Execution → Data Collection → Learning / Continual Learning. Evaluation includes revalidation after each model update.
